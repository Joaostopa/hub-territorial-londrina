Coletas para o histórico

Importe um envelope JSON com source, purpose, coverage, observed_at, complete, note e records. A cobertura deve identificar a mesma busca em todas as coletas. Marque complete somente após validar todas as páginas, sem erros ou limites. Até 20.000 registros / 30 MB.

Importações ficam nesta sessão do navegador. Baixe o histórico antes de fechar. Para compartilhar permanentemente, publique o arquivo historico.json junto ao site. A nova API ainda não está conectada; nenhuma coleta paga é iniciada aqui.

O dataset importado não fornece horário de coleta. Para essa base, a referência é a exportação fornecida de 13/09/2026. Datas de publicação e atualização do anúncio são diferentes da data de coleta.

O que esta apresentação contém

Novas importações duram até recarregar a página. Coleta semanal e histórico permanente são executados no projeto Python. Esta página não faz chamadas pagas à Apify.

O IBGE apresenta a população municipal. Não atribuímos população de Curitiba ao Bacacheri ou ao círculo. Estágio extraído do texto é uma indicação do anunciante, não uma verificação de obra.
