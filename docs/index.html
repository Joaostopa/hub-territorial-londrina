Ampliar a base

Importe o JSON exportado da coleta Apify VivaReal/ZAP de Londrina. O arquivo é processado neste navegador; não é enviado ao GitHub nem altera o banco do aplicativo Python.

O que esta apresentação contém

Novas importações duram até recarregar a página. Coleta semanal e histórico permanente são executados no projeto Python. Esta página não faz chamadas pagas à Apify.

Não há estimativa de renda ou população por bairro ou círculo nesta versão.
